# JAPA: image prompt pack (35 pictures)

One picture covers 1 to 3 lines of the script (`JAPA_SCRIPT.md`). I add the words, labels, captions, zoom and music myself,
so every picture must have **no text at all**. Free AI generators write garbled letters, so we never ask them for any.

## How to make them (free tools)
Use any of these. They are free, and you can do all 35 in one sitting:
- **Google AI Studio** (aistudio.google.com) or **Gemini** (gemini.google.com): best at following a style, and lets you ask for a wide picture.
- **Meta AI** (meta.ai or the WhatsApp chat): fast, but sometimes makes square pictures.
- **Bing Image Creator** (bing.com/create): good, with a daily limit.

Steps for every picture:
1. Paste the **STYLE** block, then the **CHARACTER** block (only if the prompt mentions Tunde), then the scene line.
2. If a picture comes out square, add "wide cinematic 16:9 frame" and try again.
3. Pick the best of the results and save it as the number: `01.png`, `02.png` ... `35.png`.
4. If one is a bit wrong (extra fingers, a bad face), just make it again. Faces can be small, so don't spend long on tiny details.
5. Send me the pictures as **documents** (or a Google Drive folder link), not compressed photos.

If the character looks different in each picture, that's fine. Keep the same clothes (mustard hoodie, round glasses) and it will feel like one story.

## STYLE (paste first, every time)
```
Flat 2D editorial illustration in a hand-cut paper style, soft film grain, warm earthy palette of terracotta, mustard yellow, deep teal and cream with small Nigerian-green accents, thick simple shapes, no outlines, soft shadows, calm and slightly melancholic mood, wide cinematic 16:9 frame, absolutely no text, no letters, no numbers, no logos.
```

## CHARACTER (paste after STYLE when Tunde is in the scene)
```
Tunde: a Nigerian man in his mid-20s, brown skin, short black hair, round glasses, mustard-yellow hoodie.
```
